      How containment works
      
    
        
      
      1. The host never imports your code. It is written to a throw-away directory
        and executed by a separate runner process.
        2. 
      
      2. Layer 1 - audit hook. A Python audit hook
        refuses process launches, network calls, native code, interpreter introspection and any file
        write or delete outside one scratch directory, and logs each refusal.
        3. 
      
      3. Layer 2 - container. In production the runner lives in a container with no
        network, a read-only root filesystem, no capabilities, a non-root user, and pid, memory, CPU
        and wall-clock limits.
        4. 
      
      4. Only numbers come back. The sandbox returns a list of +1 / -1 / 0 per bar.
        The backtest is replayed on the host from those numbers alone.
